# Word Memory Game (単語記憶ゲーム)

英語フレーズを効率的に覚えるための、ゲーム要素を取り入れた単語帳アプリケーションです。スマートフォンやPCのブラウザから、1つのHTMLファイルだけで手軽に動作します。

## 🚀 特徴
- **1ファイル完結**: `index.html` 単体で動作し、特別なサーバーサイドの仕組みは不要です。
- **モバイルフレンドリー**: スマートフォンでの操作に最適化された直感的で美しいUIデザイン。
- **ゲーム感覚での学習**: 忘却曲線やゲーム要素を取り入れ、楽しく英語フレーズを暗記できます。
- **柔軟なカスタマイズ**: ローカルのテキストファイル（単語帳）を編集するだけで、簡単にフレーズの追加・変更が可能です。

## 📁 ディレクトリ構成
- `index.html`: ゲーム本体（HTML/CSS/JavaScript）
- `2025-2026.txt`: 2025-2026年コースの英語フレーズデータ
- `2026-2027.txt`: 2026-2027年コースの英語フレーズデータ
- `単語帳の更新方法_方法1.txt`: 単語データ更新に関する詳細マニュアル
- `ゲーム要件.md`: 開発時の要件定義メモ
- `README.md`: 本書（このファイル）

## 🛠 起動方法
ブラウザのセキュリティ制限（CORS）を回避し、単語帳データの変更を自動でゲームに反映させるため、以下のいずれかの方法で起動することを強く推奨します。

### 推奨：ローカルWebサーバーでの起動 (http://...)
1. **VSCodeの「Live Server」を使用する場合**
   - 本フォルダをVSCodeで開きます。
   - `index.html` を開き、右下の「Go Live」をクリックします。
   - ブラウザが起動し、`http://localhost:5500/...` でゲームが開始されます。
2. **その他のローカルサーバーを使用する場合**
   - Pythonがインストールされている場合、本フォルダで以下を実行してサーバーを起動できます。
     ```bash
     python -m http.server 8000
     ```
   - その後、ブラウザで `http://localhost:8000/index.html` にアクセスします。

### 直接ダブルクリックで起動する場合 (file://...)
- `index.html` をダブルクリックしてブラウザで開きます。
- **注意**: この方法ではローカルのテキストファイル（`2026-2027.txt`など）を自動で読み込むことができません。単語帳を更新した場合は、ゲーム画面最下部の「⚙️ 単語データのカスタマイズ・編集」からテキストファイルをドラッグ＆ドロップして適用してください。

## ✍ 単語帳の更新方法
ゲームで使用する単語やフレーズは、ローカルのテキストファイル（`2026-2027.txt` や `2025-2026.txt`）を編集することで簡単に追加・変更できます。

1. 更新したいコースのテキストファイルをテキストエディタで開きます。
2. **「英語フレーズ [半角スペースまたはコロン :] 日本語訳」** の形式で、1行に1フレーズずつ入力します。
   ```text
   streamline 効率化する
   Our efforts finally paid off 私たちの努力がようやく実を結んだ。
   worth trying : 試す価値がある
   ```
   ※ ゲームに不要な空行や解説コメントは自動的に除外されるため、自由に記述して問題ありません。
3. ファイルを上書き保存し、ブラウザでゲーム画面を再読み込み（リロード）すると最新データが反映されます。
